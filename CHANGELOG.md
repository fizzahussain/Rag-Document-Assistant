# Changelog

All notable changes to the RAG Document Assistant project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-04

### Added
- Repository initialization, Git hygiene, and GitHub workflows.
- PostgreSQL ORM models and Alembic migration tracking.
- Secure file ingestion and multi-format document extractors (PDF, DOCX, TXT, MD, CSV, HTML, JSON).
- Text chunker and configurable vector embedding service.
- Qdrant vector store integration and user-isolated search engine.
- FastAPI REST API endpoints and Gradio web interface.
- Docker Compose configuration and pytest test suite.
